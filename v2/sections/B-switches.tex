\section{Runtime Switches}\label{sec:switches}

Every arm of \cref{sec:ablation} is the same binary with one switch changed.
\Cref{tab:switches} lists them. All ablation switches are measurement
apparatus: each prints a warning at start-up, and those that leave the host
copy or the slot stale also mark the run's output as numerically invalid.
