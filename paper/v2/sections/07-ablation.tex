\subsection{What Each Building Block Is Worth}\label{sec:ablation}

Each block of \S\ref{sec:mm} is isolated by an arm that removes the mechanism
while leaving everything else in place, rather than by subtracting totals.
\Cref{tab:ablation} reports the arms; \cref{tab:ladder} carries their effect to
the target configuration through the capacity model. All per-step overhead is
expressed through the two coefficients of $\Delta T = F + c\,r$ (\S\ref{sec:model}),
fitted only on rider counts below the knee: fitting across it raises the slope
and lowers the intercept together, overstating $c$ and understating $F$.

\paragraph{The rolling cache carries the result.} With the copy stream
serialised, a rider costs 7.20\,ms of step time, more than twice what a token is
worth at the baseline rate; overlapped, it costs 0.93\,ms. The difference is the
transfer itself: the harness reports 6.17\,ms of link time per rider at this
context, and the two arms differ by 6.27\,ms. Below the knee nothing of it
remains: removing the bytes while keeping every launch moves $c$ by
$-0.010$\,ms, so what $c$ measures is exposed work only, and it does not depend
on context (0.53 and 0.49\,ms at ctx 128 and 256). The deferred write-back halves
the fixed cost: a blocking device-to-host copy per layer was a synchronisation,
not a transfer, costing 446$\times$ the time of the few kilobytes it moved.

\paragraph{Addressing removes the context term.} One slice per rider instead of
one entry per rider block cuts the table's host cost 87$\times$ at ctx 512, and
the cost no longer moves with context: a 3.7$\times$ change in block count leaves
the timer unchanged. Before the change, the per-rider cost grew with context
faster than the budget it must beat, so no context length paid; after it,
longer context helps. The layout change matters for the same reason: an
interleaved $K$/$V$ layout turned every run into a host-side gather, a host
memory copy that no interconnect can speed up.

\paragraph{What fusion would buy.} With both data-path mechanisms disabled, a
remainder of 1.94\,ms per step survives at $L{=}64$: the second attention call.
It is now the larger part of $F$, so fusing the calls is the next block.
\planned{fusion is not implemented; its row in \cref{tab:ladder} is a
projection.}

\paragraph{The ladder.} \Cref{tab:ladder} shows why every block is needed. As
first built, a rider cost more than a token is worth, so the gate failed and no
rider count could pay at any bandwidth. Addressing passed the gate, but with the
fixed cost still at 13.4\,ms the two riders the knee admits only broke even. The
deferred write-back is what made them pay. Admission (\cref{alg:admit}) turns
any failing state into $1.00\times$ rather than a loss, by admitting no riders.
