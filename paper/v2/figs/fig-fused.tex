\caption{\textbf{Fused tier attention (planned).} Today every layer runs attention
twice: once over all rows against the paged pool, with rider rows masked to a
single key, and once over the gathered rider rows against the rolling slot, whose
output is scattered back. A fused kernel would let each row select its own KV
region, removing one launch, the gather and the scatter per layer. The cost of the
second call is measured in \S\ref{sec:ablation}.
\planned{panel (b) is a design; no fused kernel exists.}}
