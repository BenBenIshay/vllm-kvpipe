\caption{\textbf{Three address spaces, and the one that is forced.} A host-tier
request's KV is addressed by a \emph{private} block id space (i), compacted once
per step into a dense device-side range (iii) that every layer reuses. Keying the
mirror by device block id (ii) is not an optimisation we declined: releasing a
block --- the point of the feature --- nulls its table entry and returns the id to
a free list that promptly reissues it, so the mirror would lose its read mapping
\emph{and} alias another request's data.}
